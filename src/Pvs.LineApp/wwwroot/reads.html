Automatic machine reads

When a switch is ON, PVS reads that report on its own in the background. When OFF, PVS never fires it automatically — you read it on demand from the Machine Inventory page (“⏸ Stop machine → Read”). Reads are one-way queries; they never control the machine. Changes take effect immediately and survive a restart.
Auto per-feeder read (C1Z)
Background rotation that asks each machine for its per-feeder pickup counts (~one machine every 45 s). Turn OFF to keep the serial line quiet and read feeders only when you stop a machine.
—
Auto board-count read (C1M)
Automatic reads of each machine’s own board counter to keep PVS’s lot count anchored (recovery after a serial gap / restart). Turn OFF to read the board count only on demand.
—
Machine-tally sync from per-feeder pickups
On every landed C1Z, the machine’s own panel count (median of successful pickups ÷ mount over its feeders) is compared with PVS’s board tally for that machine. Shadow only records what it would correct (see /api/tallysync). Apply corrects the tally — and the feeders by the difference — the same way as the operator’s HMI sync. A report from before the operator’s per-lot reset is ignored.
