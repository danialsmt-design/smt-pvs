📦 Standby reel check verify spares on the rack

Scan every standby (spare) reel physically on the line rack. ✓ = confirmed present. When you've scanned them all, any reel still un-ticked is a phantom — the system holds it as a spare but it isn't on the rack (usually an old empty never scanned back); report those to your supervisor to zero. A reel that's actually loaded on a machine, or one from another line, is flagged as you scan it.

🔧 Manual feeder lists breakdown / reshuffle

When a machine is down and its feeders are shared across the running cells, load each machine's exported feeder-list CSV from the pen drive (Sony or JUKI export). PVS verifies against these files instead of the DB until you reload. Load a file for every running machine — the loaded total must match the Canon BOM part count. You decide which machine a file goes to, and Skip any cell that is not running this lot — a skipped machine's feeders drop out of the check until you put it back.

🔌 Serial COM test machine link health

Live per-machine serial check — is each mounter's COM port open and answering. PASS = port open, online, receiving. FAIL = port not open / no answer. STALE = open but no message in 10 min (check cabling, or the machine is parked). JUKI manual machines have no serial port.
